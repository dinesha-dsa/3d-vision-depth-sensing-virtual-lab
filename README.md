# 3D Vision & Depth Sensing Virtual Laboratory v1.0

Interactive browser-based teaching lab for Robotics & Computer Vision — Module 4.

## Included
- Stereo geometry, disparity and depth (`Z = fB/d`)
- Interactive baseline, focal length and object depth
- Synthetic depth map with pixel sampling
- MRI/CT synthetic slice-stack and segmentation visualization
- 3D volume reconstruction concept
- Local real-image upload: grayscale, threshold, edge view
- Editable OpenCV/Python StereoSGBM starter code

## GitHub Pages
Upload these files to the repository root, then:
Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Scope
The MRI/CT section uses synthetic educational imagery and is not a diagnostic medical system.
